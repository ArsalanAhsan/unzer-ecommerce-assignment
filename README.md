# Unzer E-Commerce Assignment

Take-home assignment for designing and implementing an e-commerce backend with Unzer payment integration.

## Project Overview

This repository contains the architecture document and Spring Boot implementation for the Unzer take-home assignment. The goal is to design a scalable e-commerce backend with a working checkout and payment flow integrated with the Unzer sandbox.

## Tech Stack

- Java 17
- Spring Boot
- PostgreSQL
- Maven
- Docker
- Unzer Payment API

## Repository Structure

```text
backend/          Spring Boot application
architecture.md   Architecture document
docs/             Supporting diagrams/images
```

## Getting Started

Setup and run instructions will be added once the Spring Boot application is initialized.

> **Important:** Never commit Unzer API keys or other secrets to this repository.
